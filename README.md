# Kisw Market

A responsive online selling product storefront built with HTML, CSS, and JavaScript.

## Features

- Hero section with clear calls to action
- Product cards with add-to-cart behavior
- Live cart summary with subtotal, shipping, and total
- Checkout details form for demo orders
- Responsive layout for mobile and desktop shoppers

## Run locally

Open `index.html` in a browser, or serve the folder with any static file server:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

> This is a demo storefront. Connect the checkout form to a payment provider before accepting real orders.
